Proje Adı: Recipe App (React Native + Node.js + MySQL)

Bu proje, React Native ile geliştirilmiş bir mobil uygulama ve Node.js/Express ile yazılmış bir backend API'den oluşmaktadır. Veritabanı olarak MySQL kullanılmıştır.

Yapı:
- Mobil uygulama: React Native (Android için derlendi)
- Backend: Node.js + Express
- Veritabanı: MySQL

Özellikler:
- Kullanıcı kayıt ve giriş sistemi
- Tarif ekleme, listeleme, favorilere ekleme
- Kendi tariflerimi görüntüleme
- Favori tariflerim ekranı
- Detay sayfası
- Backend ile canlı veri alışverişi

Kurulum ve Çalıştırma:
- Mobil uygulama için: `npm install` ve ardından Android Studio veya EAS Build ile APK oluşturulabilir.
- Backend için: `cd server && npm install && node index.js`
- MySQL servisinin çalışıyor olması gerekir.

Yaşanan Sorunlar ve Notlar:
- Android build sırasında bazı native hatalar ve bağımlılık sorunları yaşandı, çözüm için gereksiz bağımlılıklar temizlendi.
- Firebase, Flipper ve MultiDex gibi modüller çıkarıldı.
- Proje sonuna yetiştiremediğim veya eksik kalan bir kısım olmadı, tüm temel fonksiyonlar çalışır durumda.
- Geliştirme sürecinde Expo EAS Build ve Android Studio ile APK oluşturma denemeleri yapıldı.
- Kodun tamamı ve backend dosyaları GitHub'a yüklendi.
